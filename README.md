## 核心原则

- 有理有据：每个条件附理由与证据等级（制度 / 实证 / 经验 / 假设）。
- 有迹可循：每个数值与结论可回溯到来源文档、URL、披露日期与原文片段。
- 可复现：时点数据 + 参数版本 + 代码版本 + 数据快照 → 同一结果。
- 本地优先、全量采集：所有数据落在本地数据库；采集全部上市股票 × 可得全部历史 × 全部数据类别。
- 不承诺收益：所有区间与情景均附前提与失效条件。

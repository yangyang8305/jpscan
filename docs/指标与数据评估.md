# 指标与数据评估

这份文档说明本工具用哪些数据和指标来筛选日本股票、为什么这样选、证据有多强、现在还做不到什么。它写给不熟悉金融的读者。机器读取的版本是 `config/metric_registry.yaml`，92 个指标的公式、字段和来源都在那里；公式与字段的基础定义见规划文档附录 B。

评估日期 2026-11-07。结论来自三份独立评估（学术证据、从业者判断、实测数据可得性），有分歧的地方在第 7 节列出。

## 1. 先说结论

- **筛选围绕六个问题，而不是几十个指标。** 92 个考虑过的指标中，13 个参与判断，15 个只用来排除或降级，55 个只展示，9 个不用。
- **这些选择还没有用收益回测过。** 下面说的「证据强」是指外部研究的证据强，不是本工具已经证明有效。实测部分只测了数据覆盖率和股票之间的相关性。所有阈值都是事先定的，没有根据结果调整。
- **最强的日本专属证据是公司对未来利润的指引。** 公司发年报时给出的明年预测，比实绩本身更能解释之后的股价（第 3 节）。
- **免费版数据有两个硬伤。** 一是所有数据晚 12 周，而指引、下跌反弹这类信号的有效期大多短于 12 周；二是没有负债、利息和公告信息，所以僵尸企业、回购、下跌原因都判断不了。
- **最该先做的两件事都不花钱：** 每天采集 TDnet 公告，注册 EDINET Key（第 9 节）。真要按这些信号动用资金时，再升级到 J-Quants Standard（¥3,300/月）。

## 2. 每类数据回答什么问题

| 数据 | 它能回答 | 它回答不了 | 来源 |
|---|---|---|---|
| 股价与成交额 | 跌了多少、比同行弱多少、买卖得动吗 | 为什么跌 | J-Quants |
| 每日估值字段 | 相对净资产和盈利预测贵不贵 | 这个价格合不合理 | J-Quants |
| 决算短信的实绩 | 赚了多少、资产多大 | 负债和利息明细 | J-Quants |
| 决算短信的公司预测 | 公司怎么看未来、预测有没有变 | 预测准不准（要多年记录） | J-Quants、TDnet |
| 现金流 | 利润有没有变成现金 | 季度情况（只有半年和全年才基本齐全） | J-Quants |
| 分红与股数 | 公司还给股东多少钱 | 分红是一次性的还是长期政策 | J-Quants |
| 适时披露公告 | 回购、增发、丑闻、下跌原因 | 31 天以前的历史（免费渠道） | TDnet |
| 有价证券报告书 | 负债、利息、股东是谁、资产质量 | 最新季度（一年或半年一次） | EDINET |
| 交易所名单 | 是否被监管、是否面临退市 | 经营好坏 | JPX |
| 信用与做空余额 | 借钱买入和做空的拥挤程度 | 日本的收益证据不足 | J-Quants 付费版 |
| 新闻标题 | 发生过什么 | 涨跌方向（研究中准确率约 0.53） | RSS，只存标题 |
| 分析师一致预期、四季报 | 市场真实预期 | 不能接入程序，条款禁止自动取得 | 只能人工看 |

## 3. 选中的六个证据家族

每个家族回答一个问题。家族之间尽量独立，同一家族内的指标合起来只算一份证据。这样做的原因是：十个高度相关的估值指标同时变好，并不等于有十份证据。

「命中」的阈值都是在同行业内比较，全部是先验值。「今天能判断的比例」是实测的，回填完成后会变化。

| 家族 | 回答的问题 | 参与判断的指标 | 怎样算命中 | 外部证据 | 今天能判断的比例（Prime / Standard / Growth） |
|---|---|---|---|---|---|
| 相对估值 | 考虑赚钱能力和同业后，它便宜吗 | ROE 调整后 PBR 残差、预期盈利收益率、营业现金流收益率 | 已知至少 2 项，其中 2 项进入同业最便宜的 30% | 中等偏强，2010 年后变弱 | 94% / 90% / 15% |
| 股东回报 | 实际还给股东多少现金 | 预想股息率、净股东回报率 | 任一项进入同业前 30%，且分红有利润覆盖 | 中等 | 92% / 91% / 93%（Growth 不计入） |
| 经营质量 | 生意本身赚不赚钱、在变好吗 | 7 项简化 F-Score、营业利润/总资产 | F-Score 至少 5 分，或盈利能力进入同业前 30% | 中等，有冲突 | 8% / 13% / 18% |
| 指引变化 | 公司对未来利润的说法刚变好了吗 | 翌期指引意外、期中业绩预想修正 | 指引意外进入前 30%（60 天内），或上调幅度进入上调公司的前 30%（30 天内） | 翌期指引强，期中修正中等 | 95% / 94% / 85% |
| 资本行动 | 最近有没有用真金白银回报股东 | 配当预想上调、股数净减少（将加入回购公告） | 任一发生 | 回购强，但现在拿不到公告 | 回购 0%，其余待回填 |
| 价格错位 | 是否比同行跌得特别多，且不像有坏消息 | 1 个月行业调整后跌幅（无消息下跌用于提高排序） | 进入全市场跌幅最大的 10% | 中等，样本偏老 | 100% / 100% / 99% |

**怎么知道这几个家族够独立？** 我用 2026-08-14 这一天的数据算了同行业内的秩相关（1 表示排序完全相同，0 表示无关）：

| 两项指标 | 相关 | 含义 |
|---|---|---|
| 1 个月跌幅 对 所有估值和质量指标 | 绝对值不超过 0.15 | 基本是另一回事 |
| 业绩预测变动 对 估值、质量、股息 | 不超过 0.23 | 基本是另一回事 |
| 股息率 对 预期盈利收益率 | 0.43 | 有重叠，但不是同一批公司 |
| 营业盈利能力 对 账面市值比 | −0.30 | 便宜的公司往往赚钱能力弱，所以二者搭配才有意义 |
| ROE 残差 对 预期盈利收益率 | 0.77 | 高度相关，所以放在同一家族，只算一份证据 |

这只是单日横截面，用来检查有没有重复，不能说明未来收益。

**选中指标的理由：**

| 指标 | 大白话 | 为什么选 | 证据（G 编号见规划文档附录 G） |
|---|---|---|---|
| ROE 调整后 PBR 残差 | 同行业、赚钱能力相近的公司里，它的估值低多少 | 回答「便宜得有没有道理」。这是自己构造的公式，没有直接检验过 | G2-05、G2-06、G2-07 间接支持。实测：原始 PBR 最便宜的 30% 中 44% 预期 ROE 低于 5%，调整后降到 21% |
| 预期盈利收益率 | 按公司预测，每 100 元股价一年能赚多少 | 日本市场以公司预测为锚；用它而不是 PER，亏损公司才不会悄悄消失 | G2-01；预测有乐观偏差（G2-15，未核实） |
| 营业现金流收益率 | 一年收到的经营现金相当于市值几成 | 绕开部分会计问题，是相对独立的视角 | G2-01、G2-02，样本偏老 |
| 预想股息率 | 按预告分红，一年拿回股价的百分之几 | 日本少有的长期稳定信号 | MSCI 2026、G2-34，多为指数和卖方资料 |
| 净股东回报率 | 分红加回购减增发，占市值多少 | 比股息多抓回购 | Walkshäusl 2016，日本未单列 |
| 7 项简化 F-Score | 7 个是非题判断财务是否在变好 | 同时处理价值陷阱和基本面改善 | Walkshäusl 2020，大盘股也显著；日本未单列，7 项版未检验 |
| 营业利润/总资产 | 全部资产每年赚多少本业利润 | 单独选股弱，和估值搭配有增量 | 支持与反对都有（G2-02、G2-03 反对） |
| 翌期指引意外 | 年报给的明年预测比今年实绩高多少（相对市值） | 最符合日本制度的信号 | G2-19（60,124 个公司年，全文已读）、G2-14 |
| 期中业绩预想修正 | 财年中上调或下调全年预测的幅度 | 不解析文件也能从每日数据反推（91.8% 与文件数值相差不足 1%） | G2-17（单篇）；近期复现未找到 |
| 配当预想上调 | 公司上调分红预告 | 披露完整，数据干净 | G2-24，样本偏老 |
| 股数净减少 | 流通股变少，说明在回购 | 回购公告的滞后替身，只作是否判断 | 连续排序的证据互相矛盾 |
| 1 个月跌幅 | 上月比同行跌得多的，本月倾向反弹 | 错杀方向最直接的学术信号 | 东证 1975–1997 研究等；近期扣成本的检验未找到 |
| 无消息下跌 | 大跌时没有公司新闻的，反弹远好于有坏消息的 | 提示「原因不明」可能反而最好 | Tsukioka 等 2017，样本止于 2010 |

## 4. 家族怎么组成候选篮子

| 篮子 | 目标 | 必须命中 | 另需 | 不得出现 |
|---|---|---|---|---|
| B1 低估反转 | 便宜，且有另一类证据说明不只是便宜 | 相对估值 | 经营质量、股东回报、指引变化、资本行动至少一个命中 | 经营质量差（F-Score 不超过 2）、近期下修 |
| B2 指引改善（原「质量成长」） | 公司刚把未来说得更好，生意说得过去 | 指引变化 | 经营质量（数据够时）；预期盈利收益率不在同业最差 30% | 金融业不进此篮 |
| B3 错杀修复 | 比同行跌得多，但预期和分红没有同等恶化 | 价格错位 | 基本面完好检验、下跌归因 | 近期下修 |
| B0 特殊情形 | TOB、MBO、行动型股东等 | 事件本身 | 不评分，单独呈现 | 当前数据下为空 |

**数据不够时怎么办。** 这是本工具的硬规则：

- 一个家族在某市场能判断的比例低于 60%，就不能作必要条件。
- 如果它是篮子的核心条件（上表「必须命中」），这个篮子在该市场暂停，不能跳过这一步。
- 如果它只是附加条件，就放行，但标记「低置信」，并写明没有检查。
- 数据缺失绝不算通过，也绝不算不通过。

因此现在经营质量家族只能判断一成左右的公司，不作必要条件；回填完成后每次运行重新计算，它会自动生效。相对估值在 Growth 只有 15%，所以 B1 在 Growth 暂停。

**规模检查。** 按以上规则，2026-08-14 这一天在流动性核心池（1,920 只）内约有：B1 187 只、B2 83 只、B3 186 只，B1 与 B2 重叠 35 只。这个数字只说明筛选不是过松或过严，不说明它们能赚钱；当天处于决算季，事件型数字偏高。

同一篮子内按命中家族的指标分位等权排序。不拟合权重，因为文献里的显著性不能换算成权重，而现有数据也不够拟合。

## 5. 门槛：先排除，不打分

门槛回答「能不能碰」，不回答「好不好」。它们大多没有收益证据，目的是避免永久损失或口径错误。

| 门槛 | 大白话 | 处理 | 现在能查吗 |
|---|---|---|---|
| 制度红旗 | 被监管、改善期间、资不抵债 | 排除 | 能；持续经营注记、不当会计等文本项要等 TDnet |
| 流动性 | 成交额够不够买卖 | 排除 | 能 |
| MS 权证 | 持续压低股价的融资方式（G2-27） | 排除 | 不能，要 TDnet |
| 大额增发 | 股数一年增加 10% 以上（G2-26） | 降级 | 回填后能，只是事后才看到 |
| 财务困境 | 连续两年主业亏损且现金流出，或自有资本在行业最低 10% | 降级 | 部分能 |
| 行业内安全线 | 自有资本比率和同行比，不用全市场 30% 一条线 | 降级 | 能 |
| 一次性利润 | 预计净利接近或超过主业利润 | 该项估值不算命中 | 能 |
| 分红覆盖 | 预计利润不够付分红 | 该项股息不算命中 | 能 |
| 未达后强气 | 去年没完成，今年又定激进目标（G2-16：约 65% 未达成） | 指引信号打折 | 回填后能 |
| 全年目标是否现实 | 剩余期间必须多赚多少才能完成目标 | 降级 | 回填后能 |
| 并购或决算期变更 | 增长可能只是账面变化 | 降级 | 能 |
| 披露延迟 | 财报比规定晚 | 人工复核 | 能 |
| 僵尸企业 | 多年赚的钱不够付利息（Ross 2025） | 将排除 | 不能，要 EDINET |
| 偿债能力 | 利润够不够还债付息 | 将降级 | 不能，要 EDINET |
| 周期顶点 | 利润比五年平均高太多，低 PER 是错觉 | 将降级 | 不能，要 EDINET |
| 净资产质量 | 账面净资产里多少是商誉 | 将降级 | 不能，要 EDINET |

报告必须列出没检查的门槛，不能显示为通过。

## 6. 被否决或降级的，以及原因

**不再使用：**

| 指标 | 原来的位置 | 否决原因 |
|---|---|---|
| 盈利收益率减国债利率 | 低估分 | 这是逻辑问题：同一天所有股票减同一个数，股票之间的排序完全不变 |
| 价格反应比 R（跌幅除以预测降幅） | 错杀分最大项，占 40 分 | 公司没改预测时分母固定，任何跌 10% 以上的股票都算「跌过头」。实测 10% 以上的下跌中 73% 预测几乎没变 |
| 「全年预测未下修」作为基本面完好的证明 | 错杀必要条件 | 1Q 几乎不筛人：跌 5% 以上的公司 98.6% 通过，因为修正义务线前公司可以不改。3Q 和全年的情况待回填后重测 |
| 不分行业的绝对线（PER<10、PBR<1 等） | 强低估标签 | 主要在标注行业：PBR<1 在纸业占 91%，在情报通信占 9% |
| EV/EBITDA | 四大核心之一 | 日本缺乏证据，现在也算不出（接入 EDINET 后只展示） |
| 毛利/总资产 | 候选 | 算不出，且营业利润/总资产已覆盖大部分含义 |
| 増収増益连续年数 | 成长分 | 与增长率重复，一次偶发下降就归零，没有证据 |
| 手工设定的新闻事件总分 | 新闻维度 | 强度和半衰期都是假设。事件逐类展示，有证据的进入对应家族 |
| 第三方一致预期 | 成长项 | 条款禁止自动取得，只能人工复核 |

**降为只展示：**

| 指标 | 原来的位置 | 降级原因 |
|---|---|---|
| 原始 PBR | 核心 | 外部证据最多，但原始排序大半在选低 ROE 公司。保留作对照：如果残差跑不赢它，就换回它 |
| PBR<1 这条线 | 标签和催化剂 | 东证改革的说法，不是定价断点（G2-07），约 36% 的公司都满足 |
| PBR 相对自身历史分位 | 入池必要条件 | 单篇研究（G2-05）加 2 年窗口撑不起硬门槛，这 2 年又是单边上涨市。有 5 年以上历史后再检验 |
| 自由现金流收益率 | 四大核心之一 | 依据的研究其实是现金流收益率；免费数据只能用噪音很大的近似 |
| 净现金比率 | 辅助 | 证据老且是二手；实测现金超过市值一半的公司中 62% 现金小于总负债 |
| 历史收入和利润增长 | 成长分 40%，硬门槛 | 没有日本证据，且 3 年增长现在也算不出。成长改由指引信号表达 |
| 進捗率偏差 | 成长分和错杀条件 | 无学术证据；实测与公告日涨跌相关 0.36，与此后 5 日只有 0.03（单季）。能解释下跌，看不出后续收益 |
| 应计比率 | 质量分 | 日本应计异象不显著（G2-13），已含在 F-Score 内 |
| 资本成本披露 | 加 10 分 | Prime 已有 92.9% 披露，没有区分度。分析师更看重后续行动 |
| 传统 12-1 动量、均线、52 周高点 | 趋势分 | 长期接近零（G2-04、G2-10），均线阶段分类没有证据。帮助看图，不进分数 |
| 特质动量 | 未列入 | 趋势类里日本证据相对最好，但只读到摘要，通过本地检验后才可能成为第七个家族 |
| 低波动、β | 趋势分 | 日本结论不一，继续用于仓位和止损 |
| 信用、做空余额 | 错杀的需给判断 | 日本证据不足或冲突，且免费版没有。现在标为未检查，不能默认通过 |
| 规模、被忽视程度 | 加分 | 小盘溢价近年不存在（G2-04），只作其他信号的条件 |
| 持股结构、行动型股东、亲子上市、政策保有 | 质量或催化剂 | 要 EDINET；其中持股结构最有用，可用来判断指引信号的漂移是否持续（G2-19） |
| 文本情绪 | 新闻 | 措辞乐观和后续收益负相关（G2-35），不作正向信号 |

## 7. 证据有多强，怎么读

| 等级 | 含义 | 例子 |
|---|---|---|
| 强 | 日本样本大、结论较一致，或是制度事实 | 翌期指引、回购规模、制度红旗 |
| 中等 | 有日本证据，但样本老、结论有冲突或未单列日本 | 相对估值各项、股息、F-Score、期中修正、1 个月反转 |
| 弱 | 证据薄、方向未定或只有实务说法 | 资产增长、信用余额、一次性利润标记 |
| 无 | 没找到。**「没找到」不等于「已证伪」**，部分检索噪音很大 | 進捗率、政策保有的收益效应 |

**几条要记住的局限：**

- 学术样本大多止于 2010–2020。2020 年代的日本证据几乎都来自指数或卖方资料，东证 2023 年改革后的结构变化基本没有严谨研究。
- 阅读程度不同。Jinushi 2023、Walkshäusl 2020 等读了全文，不少只读了摘要或二手转引，`metric_registry.yaml` 的 evidence 字段逐条注明。
- 大部分数字没有扣交易成本。反转效应最强的恰恰是成本最高的超小型股。
- 实测只来自回填中的一段窗口，主要是 2026 年 1Q 决算季。

**三份评估的主要分歧及处理：**

| 分歧 | 各方看法 | 这里的处理 |
|---|---|---|
| 原始 PBR 要不要打分 | 研究方：证据最强，应打分；另两方：只作输入 | 只展示，但作为残差必须跑赢的对照，由检验决定 |
| 残差公式 | 两种口径 | 实测后选按市场分别回归的对数口径。全市场混合的线性口径与原始 PBR 排序相关 0.93，等于没调整 |
| 经营质量的角色 | 研究方：参与打分；数据方：只去劣 | 作确认条件，不作主排序 |
| 期中修正有多强 | 从中等到强 | 取中等，因为缺近期独立复现 |
| 单季利润意外、公告日反应 | 从业者和数据方主张打分；研究方依据 Jinushi 认为已被当日吸收 | 先展示，比较它相对指引信号的增量 |
| 急跌阈值触发 | 研究和数据方：作入池门 | 先只标事件日。入池由 1 个月跌幅承担。实测满足固定阈值的股票只有 56% 落在跌幅最大的 10% 内，固定阈值也没有检验 |
| 净现金 | 从业者：加上限后打分；另两方：展示 | 展示 |
| 付费升级的顺序 | 研究方：Light 优先；从业者：暂缓；数据方：实盘直接 Standard | 免费的先做，实盘时选 Standard，见第 9 节 |

## 8. 各行业的陷阱

通用指标在下面这些行业会读错。规则写在 `metric_registry.yaml` 的 `sector_overrides`。数字为实测，其余属制度或实务知识，未逐项核实。

| 行业 | 陷阱 | 工具的处理 |
|---|---|---|
| 银行 | 没有营业利润和营业利润预测；自有资本比率中位 5%；真正要看的规制资本、信用成本 Free 都没有 | 只比同业估值；不看现金流和质量家族；用经常利益和净利预测 |
| 保险 | 营业利润 64% 为空，通用指标不适用 | 不进自动评分 |
| 证券 | 81% 不给预测，受行情影响大 | 无预测不算负面；只看 PBR 对过去 ROE |
| 其他金融 | 杠杆就是业务本身 | 不用现金流和自有资本门槛 |
| 不动产 | 56% 的公司 PER 低于 10，低 PER 是常态；购地让营业现金流为负；利润集中在 4Q | 不计现金流收益率；F-Score 的现金项不算；看含み益和利率敏感度 |
| 电力燃气 | 85% 的公司 PBR 低于 1；燃料调整时滞；约 20% 无预测 | 只看行业内；自有资本和同行比 |
| 海运 | 利润主要来自营业外，低 PER 可能是周期顶部 | 用经常利益；周期位置现在显示未检查 |
| 商社 | 五大商社全用 IFRS，营业利润预测全空，靠持分法和资源价格 | 改用净利；其他卸売公司照常 |
| 钢铁、化学、非铁、纸、石油、矿业 | PBR<1 比例很高；在库评价损益和资源价格影响利润 | 只看行业内；周期位置现在未检查 |
| 建设、机械、SI | 1Q 进度天然偏低（建设中位 18.8%） | 不用进度下结论；看受注残 |
| 医药 | 31% 无预测，25% 用 IFRS，减损计入营业利润 | 无预测算未知；要看管线和专利 |
| 零售、外食 | 非 3 月决算多；股东优待废止引发的下跌不是错杀 | 要 TDnet 才能分清原因 |
| 情报通信、服务 | 行业太杂（600 多和 500 多只），同业比较意义弱；情报通信 PBR<1 只占 9% | 分位结果要打折看 |
| Growth 市场 | 58% 不分红，ROE 对估值解释力低，27% 无预测 | 不计残差和股息；B1 暂停 |

**不分行业的常见错误：**

- 字段为空却填 0 或行业中位，会让整个行业静默消失或排错。
- 市值单位是百万円，财务金额单位是円，混用会差 100 万倍。
- 累计值要差分才是单季。股票分割要还原，否则会被误判成增发或回购。
- 决算期变更和并购会造成假增长。
- 年报发布当天每日数据的预测切换到下一财年，这个跳变不是修正。实测占所有变动事件的 24.5%。
- IFRS 没有经常利益，商誉也不摊销，和日本准则的利润不能直接比。2027-04 起新租赁准则还会造成断点。
- 投资证券同时计入净现金和净资产，会重复计算。
